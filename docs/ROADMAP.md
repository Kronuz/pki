# Roadmap

pki is built in five steps. This repository holds the first: fingerprints, expiry checks,
keys, the authority directory's checks, identities, and secrets. The remaining steps, in
order:

1. The index, the rest of the certificate profile, and signing.
2. Rotation, backup, and recovery.
3. Xapiand's `xapiand pki` command.
4. Detent's adoption.
